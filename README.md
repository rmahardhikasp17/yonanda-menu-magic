# Hotel Yonanda - Sistem Kasir

Sistem Kasir Operasional Hotel Yonanda - Jimbaran Bandungan

## Tech Stack

- React + TypeScript
- Vite
- TailwindCSS
- shadcn/ui
- IndexedDB (offline storage)

## Features

- Manajemen Kamar (Check-in/Check-out)
- Pesanan Kantin Hotel
- Pembayaran Cash & QRIS
- Data Tamu dengan Multi-room Support
- Admin View untuk detail tamu
- Cetak Nota

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
